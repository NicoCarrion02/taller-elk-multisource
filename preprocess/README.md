This preprocess is intented to download and split data from Kaggle Hub to be used in the ELK stack.

The objective is to have the raw data splitted into 4 sources of information, like CSV, EXCEL, DATABASES and so on.

To run this preprocess, use the following:

1. In a command window:
   > install.bat

2. Run the python script:
   > py preprocess/engine.py
