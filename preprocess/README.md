This preprocess is intended to download and split data from Kaggle Hub to be used in the ELK stack.

The objective is to split the raw data into four different data sources, such as CSV files, databases, logs, JSON files, and so on.

To run this preprocess, use the following:

1. In a command window:
   > install.bat

2. Run the python script:
   > py preprocess/engine.py
